# Loop 图标方案 v1

设计方向：循环与观察。环形箭头表示 Agent 持续执行与反馈，中心圆点表示观察和定位；沿用项目的深绿色，使用暖白色符号。

生成方式：内置 image_gen，先生成概念，再编辑为平整底色。此文件是设计候选，尚未替换网页图标。

## 初始生成提示词

Use case: logo-brand.
Create ONE original, polished app icon for "Loop", a beginner-friendly coding agent whose identity is equally about an execution loop and observing what happens. This is a standalone icon design, not a mockup or a presentation board.

Design: a deep forest-green rounded-square tile, with a single bold warm-ivory symbol centered inside. The symbol combines an almost-complete flowing circular loop with one clean, gently rounded arrowhead at the upper-right, pointing along the loop, and one small perfectly round ivory observation dot in its center. Make the loop feel purposeful and continuous, with generous clean negative space and beautifully balanced optical proportions. The center dot makes the loop feel like a focused observing instrument. Favor a distinctive, coherent silhouette over a generic thin refresh pictogram. The mark occupies roughly two thirds of the tile and stays readable as a small favicon. The circular stroke and arrowhead should merge into one shape, with no awkward overlaps.

Palette: tile #315B47; mark warm ivory #F5F4EA. Flat solid colors, crisp vector-like edges, extremely restrained contemporary developer-tool branding. Smooth rounded corners, no outline around the tile. Square composition, straight-on, large single icon filling the canvas with a narrow even transparent margin; genuine transparent background outside the rounded tile.

No text or letters, no wordmark, no caption, no robot face, no brain, no sparkles, no infinity symbol, no code brackets, no realistic eye, no gradients, no lighting effects, no texture, no 3D, no drop shadow, no extra decorative elements. Deliver a clean high-resolution square image suitable for an app icon and GitHub avatar.
