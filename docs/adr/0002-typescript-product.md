# 统一为 TypeScript 产品实现

Loop 的优先级已明确为长期可用、可维护的 Coding Agent 产品高于作者个人学习。采用 Node + TypeScript，统一前后端、Agent 内核、工具实现、测试、维护脚本及 Coding 练习，以减少长期跨语言维护并集中产品投入；接受迁移和学习成本，TS 的采用趋势不构成未来无需重构的保证。

用户已认可暂缓新增功能、先完成迁移，并接受 Node 启动前置条件。用户已确认最终范围，本决策取代 ADR-0001 的 Go + TS 路线。

## 范围与验收

- 完成现有产品行为迁移，维持模型调用、工具回执、预算停止、错误处理、连续对话、轨迹及实际执行源码之间的对应关系。
- 将 Go 修复练习改为 TS 练习，保留受限文件写入、内容指纹、容器执行、输出限制、超时及清理验证。
- 新版从空历史开始；旧记录与 Go 练习不要求回看或继续执行。新版本使用 ~/.loop/ts-runs；原 ~/.loop/runs 及 .agent_state 数据原样保留作为归档，确保可以回退。
- 当前维护的执行代码统一 TS；HTML、CSS、JSON 等资源保留适合的格式。旧版本和多语言对照实验依据保存在版本历史中。
- 以固定模型响应、文件和进程边界检查、前端检查及真实运行验证等价行为；历史兼容按上述范围明确排除。
