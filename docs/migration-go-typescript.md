- 最终 TypeScript 界面提交的真实运行 7099a9e20c724ffab2564ffac5769ac0：1 次模型请求、1 次工具调用，约 2.09 秒，随后因模型请求额度耗尽停止，没有最终回答。

原 Playwright 通道连接关闭，替换验收会话后恢复了检查能力。内置浏览器的下载事件等待器未捕获事件，但文件实际已保存到 Downloads，内容核对通过；没有将工具事件超时当作应用导出失败，也没有重复触发导出。

以上耗时属于不同运行条件下的验收记录，不用来宣称 Go 的跨语言性能提升。实际记录位于被忽略的 .agent_state/runs/。
