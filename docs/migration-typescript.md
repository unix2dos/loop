## 当前实现

前后端、Agent 内核、工具、测试、维护检查与修复练习使用 TypeScript。后端通过 Node 24.12+ 的原生类型剥离运行，网页仍由 tsc 构建；没有新增 Agent 框架。现有 TypeScript 编译器也用于提取实际函数源码、定位 JSON 原始行号。Node 的运行支持见[官方说明](https://nodejs.org/api/typescript.html)。

保留 Chat Completions 请求格式、会话标识、逐批工具回执、请求与工具预算、动态上下文、单活跃任务、错误回传、JSON/JSONL 持久化、续聊及轨迹展示。新增运行将 TS 源码快照与构建摘要一起保存。生产边界仍检查输入类型与权限，静态类型不替代运行时验证。

Go 平均值练习已换为 TypeScript：只允许修改 average.ts，检查读取时的 SHA-256，测试文件与 package.json 受保护。Node 测试容器使用固定镜像摘要，保持断网、非 root、只读挂载、资源限制、输出上限、退出状态与清理确认。公开运行模式禁止 Coding 练习与本地编辑器调用。

旧记录不承担新版回看或续跑兼容。新版默认使用 `~/.loop/ts-runs/`；原 `~/.loop/runs/` 的 20 份运行、60 个文件保留，切换前后 SHA-256 全部一致。主服务已切换到本机 8877，沿用 glm-5.3-flash，新历史为空。
